# 悬置之境 (Suspension Realm)

SillyTavern 酒馆巡查插件：静默地盯着酒馆里正在发生的一切，把「跑偏」和「报错」归档到面板，能复制、能在下一轮自动注入给模型矫正。

## 功能

| # | 模块 | 状态 | 说明 |
|---|------|------|------|
| 3 | 插件巡查 | ✅ 已上线 (v0.1.0) | 静默捕获运行中插件的报错 / 失败（`console.error` / `console.warn` / 未捕获异常 / 未处理 Promise 拒绝），归档到面板，可搜索 / 过滤 / 复制，不弹窗、不打断。 |
| 1 | 预设启用巡查 | 🧭 规划中 | 绑定预设，每轮检查预设是否被模型读取并实施，冲突标注、下轮自动注入矫正。 |
| 2 | 文风注入自检 | 🧭 规划中 | 标记预设中的文风段落，每轮自检正文是否脱风，脱离下轮自动注入矫正。 |
| 4 | 人设巡查 | 🧭 规划中 | 绑定当前人物卡，每轮检查是否 OOC / 超雄等，冲突归档 + 下轮静默注入矫正。 |

功能 1/2/4 的「巡查判定」统一走一个**独立可配的裁判 endpoint**（在面板「总览 → 裁判引擎设置」里填 URL / Key / Model），与聊天主模型互不干扰。插件巡查不依赖裁判，开箱即用。

## 安装

把本目录放到 SillyTavern 的第三方扩展目录，重命名为 `suspension`：

```
public/scripts/extensions/third-party/suspension/
  ├── manifest.json
  ├── index.js
  └── style.css
```

重启 / 刷新酒馆后，在扩展列表开启「悬置之境」，左侧扩展菜单出现「悬置之境」入口。

## 使用（插件巡查）

1. 打开面板 → 「插件巡查」页签，默认已启用。
2. 之后酒馆里任何插件的报错 / 失败会被静默归档到这里（不弹窗）。
3. 顶部可切换来源、按插件筛选、搜索消息；每条可点「复制」，或「复制全部」批量导出。
4. 「清空」删除全部归档。

## 设计约定

- **静默优先**：巡查与归档全程不弹窗、不打断对话，冲突只进面板。
- **可复制**：每条归档带时间 / 来源 / 插件 / 消息 / 堆栈，点一下即复制。
- **不篡改行为**：接管 `console.error/warn` 只做记录，原始输出照常，不影响其它插件。
