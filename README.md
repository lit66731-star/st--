# 悬置之境 (Suspension Realm)

SillyTavern 酒馆巡查插件：静默地盯着酒馆里正在发生的一切，把「跑偏」和「报错」归档到面板，能复制、能在下一轮自动注入给模型矫正。

## 功能

| # | 模块 | 状态 | 说明 |
|---|------|------|------|
| 3 | 插件巡查 | ✅ 已上线 (v0.1.0) | 列出「运行中 / 未运行」插件清单；静默捕获运行中插件的报错 / 失败（`console.error` / `console.warn` / 未捕获异常 / 未处理 Promise 拒绝），归档到面板，可搜索 / 过滤 / 复制，不弹窗、不打断。 |
| 1 | 预设启用巡查 | ✅ 已上线 (v0.2.0) | 绑定酒馆预设后把预设里的条目逐条拉出，每轮由独立裁判判定：遵循亮绿灯、冲突 / 没遵循亮红灯、本轮未使用亮白灯；冲突归档 + 下一轮自动注入矫正。 |
| 2 | 文风注入自检 | 🚧 进行中 (v0.5.0) | 绑定预设并勾选「文风段落」（可多个）已上线；每轮脱风自检 + 注入矫正待接入。 |
| 4 | 人设巡查 | 🧭 规划中 | 绑定当前人物卡，每轮检查是否 OOC / 超雄等，冲突归档 + 下轮静默注入矫正。 |

功能 1/2/4 的「巡查判定」统一走一个**独立可配的裁判 endpoint**（在面板「总览 → 裁判引擎设置」里填 URL / Key / Model，可点「拉取模型」从接口拉出可用模型列表弹窗点选，支持 OpenAI / Ollama 两种返回格式），与聊天主模型互不干扰。插件巡查不依赖裁判，开箱即用。

## 安装

把本目录放到 SillyTavern 的第三方扩展目录，重命名为 `suspension`：

```
public/scripts/extensions/third-party/suspension/
  ├── manifest.json
  ├── index.js
  └── style.css
```

重启 / 刷新酒馆后，在扩展列表开启「悬置之境」，左侧扩展菜单出现「悬置之境」入口。

## 使用（插件巡查）

1. 打开面板 → 「插件巡查」页签，默认已启用。
2. 顶部「插件清单」实时列出酒馆里**运行中**与**未运行**的插件（含类型 / 版本），点「刷新插件列表」可重新读取。
3. 之后酒馆里任何插件的报错 / 失败会被静默归档到下方（不弹窗）。
4. 可切换来源、按插件筛选、搜索消息；每条可点「复制」，或「复制全部」批量导出；「清空」删除全部归档。

## 使用（预设启用巡查）

1. 在「总览 → 裁判引擎设置」填好接口 URL / Key，点「拉取模型」从接口拉出可用模型列表、弹窗点选（支持 OpenAI 与 Ollama 返回格式），或直接手动填模型名。
2. 打开「预设巡查」页签 → 勾选「启用巡查」→ 从下拉里选一个**你酒馆里已保存的聊天补全预设**。选中后下方会把预设里的**每个条目**逐条拉出，并带三色灯。
3. 之后每轮生成结束，插件把「每个预设条目 + 最新回复」交给裁判逐条判定：**绿灯**=被读取 / 遵循，**红灯**=冲突 / 没遵循，**白灯**=本轮未使用。
4. 若有红灯条目：冲突归档到下方（可复制 / 清空），并默认在**下一轮自动注入矫正**给模型（单轮有效，生成结束即清除，不会长期污染上下文）。
5. 「手动巡查一次」可跳过等待，立即对当前最后一轮回复逐条判定一次。

## 使用（文风自检）

1. 打开「文风自检」页签 → 勾选「启用自检」→ 从下拉绑定一个预设。
2. 绑定后下方会列出预设里的每个条目，勾选即把该条目标记为「文风段落」（可多个），已标记的条目标绿高亮。
3. 「脱风时下一轮自动注入矫正」默认开启。
4. 每轮脱风判定与注入矫正将在下一版接入（当前先完成标记与持久化）。

## 设计约定

- **静默优先**：巡查与归档全程不弹窗、不打断对话，冲突只进面板。
- **可复制**：每条归档带时间 / 来源 / 插件 / 消息 / 堆栈，点一下即复制。
- **不篡改行为**：接管 `console.error/warn` 只做记录，原始输出照常，不影响其它插件。
